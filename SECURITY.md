# Security policy

This policy applies to the static personal portfolio in this repository and to the domain `www.miguelangelodiasmagalhaes.online`.

## Supported version

Only the currently published site on the default branch (`main`) is supported.

Historical commits, forks, mirrors and copies hosted elsewhere are not supported.

## Reporting a vulnerability

Please email **miguel.softeng@gmail.com**.

Include:

- a clear description of the issue;
- the affected URL;
- steps to reproduce;
- the impact;
- browser or environment details;
- a non-destructive proof of concept, only if it is needed to understand the issue.

Do not include:

- real personal data;
- passwords;
- API keys;
- clinical information;
- data that belongs to third parties.

A reasonable effort will be made to confirm receipt and to assess legitimate reports. There is no bug bounty, no guaranteed response time, and no absolute confidentiality or legal safe harbour.

## Responsible testing

Do not perform:

- denial of service;
- destructive testing;
- social engineering;
- phishing;
- spam;
- unauthorised access to accounts or systems;
- tests against external services linked from the portfolio;
- tests against GitHub, employers, clients or institutions;
- collection or disclosure of personal data.

This file does **not** authorise testing of third-party systems.

## Scope

This policy covers only the code and content controlled in this repository and on `www.miguelangelodiasmagalhaes.online`.

It does not cover LinkedIn, GitHub, ORCID, Credly, client sites, project repositories or other external websites linked from the portfolio.
