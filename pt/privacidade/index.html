1. Introdução e âmbito

Este sítio web é o portefólio pessoal e profissional de Miguel Ângelo Dias Magalhães. Apresenta o percurso académico e profissional, competências, projetos, experiência, certificações, investigação, atividades internacionais e contactos.

O sítio web não vende produtos, não recebe pagamentos, não faz reservas nem presta ou fatura serviços diretamente. A consulta das páginas tem natureza informativa. Qualquer colaboração futura depende de contacto e de acordo autónomos.

Esta política abrange dados pessoais que possam ser tratados porque visita o sítio web ou porque decide contactar Miguel. Não abrange sítios web que abra através de ligações externas.

2. Responsável pelo tratamento

O responsável pelo tratamento dos dados pessoais para as finalidades aqui descritas é:

  • Miguel Ângelo Dias Magalhães
  • Porto, Portugal
  • Correio eletrónico: miguel.softeng@gmail.com

Não existe encarregado de proteção de dados. Questões e pedidos relativos a dados pessoais podem ser enviados para o endereço acima.

3. Dados técnicos e alojamento

O sítio web está alojado no GitHub Pages, um serviço de alojamento estático operado pela GitHub. Para entregar as páginas, manter o serviço disponível e proteger a infraestrutura, o fornecedor de alojamento e a infraestrutura de distribuição ou segurança associada podem tratar dados técnicos. Consoante o funcionamento do serviço, isso pode incluir:

  • endereço IP;
  • data e hora do pedido;
  • recurso solicitado;
  • user-agent do browser ou do dispositivo;
  • referrer, quando o browser o envia;
  • dados de diagnóstico, cache ou segurança necessários à operação do serviço.

Miguel não opera um sistema próprio de analytics neste sítio web e não tem acesso rotineiro a registos detalhados de visitantes. Quaisquer registos técnicos gerados pelo alojamento ou pela infraestrutura associada são tratados segundo os sistemas e as políticas do próprio fornecedor.

Informação adicional sobre o tratamento efetuado pela GitHub está disponível na documentação oficial de privacidade da GitHub, que pode abrir se o desejar:

GitHub General Privacy Statement

4. Contacto por correio eletrónico

O sítio web não contém formulário de contacto, sistema de contas, newsletter nem fluxo de pagamento. O botão de correio eletrónico abre a sua própria aplicação de email, com o endereço de Miguel já preenchido. Nenhuma mensagem é enviada a Miguel enquanto não decidir enviá-la.

Se enviar uma mensagem, a informação que escolher incluir pode ser tratada para a ler, avaliar e responder. Isso pode incluir o nome, o endereço de correio eletrónico, o conteúdo da mensagem, anexos e quaisquer outros elementos que voluntariamente transmitir.

Não envie palavras-passe, chaves de API, dados de pagamento, documentos de identificação ou outras informações altamente sensíveis, salvo se for realmente necessário e tiver sido acordado um canal adequado. O contacto profissional corrente não exige esse material.

5. Finalidades e fundamentos jurídicos

Os dados pessoais são tratados apenas para finalidades determinadas e com fundamento no RGPD:

  • Disponibilização, funcionamento e segurança do sítio web. Os dados técnicos necessários para entregar e proteger o sítio podem ser tratados com base no interesse legítimo (artigo 6.º, n.º 1, alínea f), do RGPD): operar um portefólio profissional público de forma estável e razoavelmente segura.
  • Resposta a contactos gerais e profissionais. Se contactar Miguel, a mensagem pode ser tratada com base no interesse legítimo (artigo 6.º, n.º 1, alínea f), do RGPD): compreender o pedido e responder.
  • Diligências pré-contratuais, quando a mensagem respeite a isso. Se escrever sobre uma eventual colaboração, projeto ou prestação de serviços, os dados necessários para apreciar esse pedido podem ser tratados ao abrigo do artigo 6.º, n.º 1, alínea b), do RGPD. Nem todas as mensagens constituem um pedido pré-contratual.
  • Obrigações jurídicas. Os dados podem ser tratados quando for necessário para cumprir uma obrigação jurídica (artigo 6.º, n.º 1, alínea c), do RGPD), por exemplo perante um pedido válido de uma autoridade.

O envio de uma mensagem de correio eletrónico não é tratado como consentimento para tratamentos não relacionados. O consentimento não é usado como fundamento genérico neste sítio web.

6. Conservação

Os contactos gerais são normalmente conservados até 24 meses após a última interação relevante. Podem ser apagados antes se deixarem de ser necessários.

Podem ser conservados por mais tempo quando exista uma relação profissional em curso, uma obrigação legal, necessidade de prova, necessidade de declarar, exercer ou defender um direito em processo judicial, ou um litígio.

Os prazos dos registos técnicos são definidos pelo fornecedor de alojamento, segundo as respetivas políticas. Este sítio web não implementa eliminação automática de mensagens ou de registos, e não se promete um apagamento automático.

7. Destinatários e fornecedores

Consoante a situação, os dados pessoais podem ser tratados por, ou disponibilizados a:

  • o fornecedor de correio eletrónico usado para receber e guardar as mensagens enviadas para o endereço de contacto;
  • a GitHub / GitHub Pages, enquanto infraestrutura de alojamento;
  • fornecedores técnicos de CDN, cache ou segurança integrados no serviço de alojamento, quando o fornecedor de alojamento os utilize;
  • autoridades públicas, se existir obrigação legal de divulgação.

Não são usadas outras categorias de destinatários neste sítio web, no estado atual. O sítio não partilha dados de visitantes com anunciantes nem com empresas de analytics.

8. Transferências internacionais

Alguns fornecedores tecnológicos envolvidos no alojamento ou no correio eletrónico podem tratar dados fora do Espaço Económico Europeu. Quando isso suceder, a transferência fica sujeita aos mecanismos legais aplicáveis no momento e às políticas do respetivo fornecedor.

Esta política não afirma a existência de um instrumento específico de transferência, como uma decisão de adequação ou cláusulas-tipo, sem confirmação oficial atual do fornecedor em causa. Se precisar de mais pormenor sobre um fornecedor concreto, pode consultar a documentação oficial desse fornecedor ou perguntar a Miguel através do correio eletrónico de contacto.

9. Cookies e armazenamento local

No estado atual, este sítio web:

  • não instala cookies próprios;
  • não utiliza analytics nem publicidade;
  • não utiliza localStorage, sessionStorage, IndexedDB nem service worker para identificar ou acompanhar visitantes;
  • não requer um banner de cookies para as suas próprias tecnologias.

Os sítios web externos que decidir visitar através de ligações podem aplicar as suas próprias políticas e tecnologias, incluindo cookies. Esses sítios são responsáveis pelas respetivas práticas.

Se mais tarde forem introduzidos cookies, analytics ou tecnologias semelhantes, esta política será atualizada e será prestada a informação ou a escolha adicional que a lei exigir. Não se afirma que um banner será desnecessário em todas as circunstâncias futuras.

10. Ligações externas

O portefólio contém ligações para outros sítios web, incluindo LinkedIn, GitHub, ORCID, Credly, páginas de projetos, sítios de clientes ou empregadores e destinos semelhantes. Essas ligações são fornecidas para contexto. Só comunica diretamente com esses serviços se decidir seguir a ligação. O conteúdo, a disponibilidade e as práticas de privacidade desses destinos regem-se pelas respetivas políticas.

11. Informação publicada no portefólio

O portefólio contém informação que Miguel decidiu tornar pública sobre o seu próprio percurso profissional. Isso distingue-se dos dados técnicos gerados quando alguém visita o sítio e dos dados pessoais contidos numa mensagem privada.

O sítio também identifica terceiros quando isso é necessário para descrever trabalho já realizado:

  • os nomes de coautores surgem no contexto de trabalhos científicos;
  • nomes, marcas e logótipos de organizações identificam experiência, formação, clientes, projetos ou tecnologias.

A publicação não significa necessariamente afiliação atual, patrocínio ou aprovação por essas pessoas ou organizações. Se estiver identificado e pretender uma correção ou remoção, pode enviar um pedido fundamentado para miguel.softeng@gmail.com. Os pedidos serão apreciados de boa-fé. Esta política não afirma que todos os terceiros tenham dado consentimento documentado para figurar no sítio.

12. Os seus direitos

Quando o RGPD for aplicável, pode ter direito a:

  • aceder aos seus dados pessoais;
  • retificar dados inexatos;
  • apagar dados, nos casos previstos na lei;
  • limitar o tratamento;
  • opor-se ao tratamento baseado em interesses legítimos;
  • receber os dados num formato portátil, quando se verifiquem as condições legais;
  • retirar o consentimento, mas apenas quando o tratamento se basear efetivamente em consentimento;
  • apresentar reclamação junto de uma autoridade de controlo.

Em Portugal, a autoridade de controlo é a Comissão Nacional de Proteção de Dados (CNPD). Informação sobre os direitos dos titulares está disponível no sítio da CNPD:

https://www.cnpd.pt/cidadaos/direitos/

Para tratar um pedido, pode ser necessário confirmar a identidade de forma razoável. Não serão exigidos documentos de identificação por defeito, e só será pedida a informação realmente necessária.

13. Decisões automatizadas

Este sítio web não realiza decisões automatizadas com efeitos jurídicos ou igualmente significativos, nem define perfis de visitantes.

14. Segurança

São adotadas medidas proporcionais para proteger o sítio web e as comunicações, incluindo HTTPS. Nenhum sítio web ou canal de correio eletrónico pode garantir segurança absoluta, e essa garantia não é prestada.

15. Alterações
